The Redolent Hour
A mobile-first GitHub Pages site for formal writing on perfume, tea, and sensory culture.
Publish on GitHub Pages
Upload every file and folder in this package to the repository named: the-redolent-hour.github.io
Open the repository's Settings.
Open Pages.
Under Build and deployment, choose Deploy from a branch.
Select the main branch and / (root), then save.
Your site will appear at: https://the-redolent-hour.github.io
Add a new article
Duplicate either HTML file inside the articles folder.
Rename it with lowercase words and hyphens, such as: my-new-review.html
Replace the title, description, metadata, and article body.
Add a new article card to index.html.
Personalise
Replace the placeholder Fragrantica href="#" link in index.html.
Change colours at the top of styles.css.
Replace the two abstract placeholder covers later with your own photos.
